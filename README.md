## The pitch

> That idea you keep describing to friends? Say it out loud once, an AI agent builds the first version tonight, and if you hate it you've lost an evening, not a year.

One sentence, 164 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. The whole entry is that sentence — no code, no explanation, nothing else in the output file.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly that sentence to `/output/entry.txt`, with no trailing newline and no extra text.

```sh
node main.ts
cat /output/entry.txt
```
